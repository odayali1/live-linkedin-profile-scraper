# What the live profile contains

The profile is fetched when you run. `checkedAt` is that time.

A hit can include the headline, about, location, country, current title, company URL, seniority, job function, industry, connections, and followers. Experience includes current roles and previous companies, with dates, employment type, and the description. Education includes the school, degree, field, and years. The same row can include skills, courses, certifications, languages, publications, patents, honors, projects, volunteer work, and organizations.

The row does not include an email address or a phone number.
